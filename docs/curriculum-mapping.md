# 교육과정 연결 (curriculum-mapping)

> 공식 성취기준 문서가 제공되지 않아 **성취기준 번호는 임의로 작성하지 않았습니다.**
> 대신 2022 개정 중학교 정보의 **단원 개념 ↔ 스테이지 활동** 연결만 정확히 기술합니다.
> (게임 데이터의 `curriculumTags` 필드와 일치)

## 학습 요소 태그 정의
핵심 정보 추출 · 문제 분해 · 추상화 · 모델링 · 패턴과 일반화 · 상태 표현 · 알고리즘 설계 · 순차 구조 · 선택 구조 · 반복 구조 · 알고리즘 실행 · 오류 수정 · 효율성 비교 · 프로그래밍으로 표현하기

## 개념 ↔ 스테이지

### 추상화 영역
- **핵심 정보 추출 / 불필요한 정보 제거**: A-01, A-02, C-01, C-03
- **문제 분해**: A-01, A-02, B-04, B-07
- **모델링(표·식·상태·그래프)**: A-02, A-03, A-08, B-03, B-04, C-03
- **패턴과 일반화**: A-04~A-07, B-07, C-02, C-07
- **상태 표현**: B-01, B-05, B-08, B-09, C-05, C-06

### 알고리즘 영역
- **알고리즘 설계**: B-01, B-05~B-09, C-05, C-07
- **순차 구조**: B-02
- **선택 구조(조건 분기)**: B-05, B-06, B-08, C-01, C-07
- **반복 구조**: B-01, C-01, C-02, C-06
- **알고리즘 실행 / 오류 수정**: B-02, B-08, C-04, C-05, C-06
- **효율성 비교**: B-01, B-05, B-06, B-09, C-02, C-05

### 추상화 ＋ 알고리즘(통합)
- **핵심 요소 추출 → 절차 설계 → 실행·개선**: 월드 3 전체(C-01~C-07)
- **프로그래밍으로 표현하기**: C-01(반복/조건), C-02(누적), C-06(이중 반복), 그리고 `src/verification/`의 solver 코드 연계

## 평가 연계
- 추상화 점수 ↔ '모델링/상태 표현' 태그
- 알고리즘 정확성 ↔ '알고리즘 실행/오류 수정'
- 효율성 점수 ↔ '효율성 비교'
- 설명 점수 ↔ 결과 화면의 서술형 '생각 정리'
