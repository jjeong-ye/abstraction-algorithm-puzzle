## 여러 정답이 인정되는 문제
- **A-08 축**: 1, 7, 13 모두 조건 만족 → 게임에서 세 값 모두 정답 처리(교재 의도 대표값 7).
- **A-07 수열**: 주 답 93 외에 부속 수열의 규칙 답(44·81·149, E)도 해설에 표시.
- **B-01·B-08·C-05**: 최소 횟수/시간이 같은 대칭 해가 여러 개 — 게임은 '최소 달성' 여부로 판정.

## 정답·해설이 교재에 없던 문제(직접 해결)
- A-04·A-05·A-06(그림 유추): 원본이 그림이라 본문에 정답 없음 → 규칙을 명확히 하여 재구성하고 특징 분석으로 정답 확정.
- B-03·B-04(모빌): 원본이 그림 → 교재의 원리(거리×무게, 아래→위 계산)를 그대로 쓰되 도형을 재구성(정답 6g·4g). 교재 5-10 예시 답(3g)과는 도형이 다름.
- B-09(최대의 길)·C-04(한붓그리기): 그림 기반 → 조건(시작·끝, 홀수점 2개)을 유지하도록 재구성하고 solver로 검증.
- B-05(9개의 동전): 교재는 '무게 방향 미상'이라 저울질 **3회**로 6번을 확정(초기 초안의 '2회'는 방향 기지 경우와 혼동한 오류 → 정정함).
- 그 외 계산·탐색 문제는 교재 정답을 solver로 재검증(book-and-verified).
