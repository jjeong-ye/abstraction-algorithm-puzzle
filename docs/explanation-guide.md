# 해설 작성 지침 (explanation-guide)

## 5단계 힌트(학생이 원할 때만 열림, 통과는 막지 않음)
1. **관찰 질문**: 무엇을 먼저 볼지 묻기(정답 미노출) — `hint1Observation`
2. **핵심 조건**: 중요한 조건 한 가지 — `hint2KeyCondition`
3. **다음 행동**: 학생이 할 수 있는 한 단계 — `hint3NextAction`
4. **단계별 풀이**: 순서 + 이유 — `guidedSolution`
5. **완전 해설**: 아래 표준 항목 — `fullExplanation`

완전 해설 열람 조건: 문제 해결 시 / 일정 시도 이상 / 학생이 '완전 해설 보기'를 직접 선택(게임은 항상 버튼 제공). 교사 모드는 즉시 열람.

## 완전 해설 표준 항목(모든 문제 공통, `fullExplanation` 키)
`answer 정답` · `key 핵심 정보` · `abstraction 문제의 추상화` · `steps 단계별 풀이` · `why 왜 이렇게 풀까` · `verify 검증` · `mistakes 자주 하는 실수` · `failReason 실패하는 이유` · `better 더 효율적인 방법` · `other 다른 풀이` · `concept 정보 개념` · `think 생각해 보기`

## 작성 수준
- 중1~3이 이해하는 한국어. 어려운 용어는 처음 등장 시 쉬운 뜻 병기(`GLOSSARY` 참고: 추상화·상태·알고리즘·조건·반복·선택·일반화·효율적인 알고리즘).
- 정답만 알려주는 2~3문장으로 끝내지 않고, **학생이 풀이를 재현할 수 있을 만큼** 구체적으로.
- 원문 의미는 바꾸지 않되, 어려운 표현은 `studentFriendlyText`로 쉬운 설명 보완.

## 교사용 추가(교사 모드 표시, `teacher` 필드)
교재 번호·쪽·원문 난이도·정답 도출/검증·프로그램 검증 결과·가능한 모든 정답·최소 이동/시간·대표 오답·오답 이유·수업 발문·개념 도입·모둠 활동·난이도 조절·프로그래밍 연결·추가 도전·평가 관점·예상 시간.
