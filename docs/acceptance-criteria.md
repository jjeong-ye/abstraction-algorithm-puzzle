# 인수 기준 (acceptance-criteria)

## 완료 정의
24개 스테이지가 모두 실행되고, 각 스테이지에 **정답·힌트·단계별 해설·완전 해설·교사용 해설**이 연결된 상태.

## 기능 체크리스트
- [x] 3개 월드, 24개 스테이지 모두 데이터·엔진 연결(`PROBLEMS` 24개, 각 `engine` 존재)
- [x] 시작→월드→스테이지→게임→결과 전 흐름 동작
- [x] 각 스테이지 5단계 힌트 + 완전 해설(12항목) 존재
- [x] 실행취소/다시시작(해당 엔진), 교사 모드, 소리·움직임·전체화면
- [x] localStorage 기록(통과·점수·시도·힌트·최소이동/시간·설명·날짜)
- [x] 평가 4축(추상화·알고리즘정확성·효율성·설명) 점수 산출
- [x] 정답 검증 solver + `test.html` 자동 테스트

## 정답 검증 기준(test.html에서 자동)
- 물항아리 최소 = 7 / 다리 = 17분 / 하노이 = 7·15·31 / 농부 = 7 / 열린 문 = 25(닫힘=제곱수) / 폭탄 첫 수 = 1(선공 승) / 축 = {1,7,13} / 최대의 길 = 31 / 4-14 = 4132 / 나이 = 73·37 / 진법 = 7 / 동전 = 10 / 선물 = 364 / 쾨니히스베르크 = 불가능 / 봉투 = 한붓그리기 가능
- DP==완전탐색, 시뮬==이론, 미니맥스==공식 등 **독립 방법 2가지 일치**로 확인.

## 다중 정답/재구성 처리
- A-08(1·7·13), A-07(부속 수열), B-01/B-08/C-05(대칭 최소 해), B-09(합 31 경로) 모두 인정.
- 그림 재구성 문제(A-04~06, B-09, C-04)는 신뢰도·재구성 사실을 answer-verification/teacher에 명시.

## 접근성 기준
- 모든 조작 버튼 키보드 포커스·Enter 실행, 색 외 글자/모양 병행, 움직임 줄이기 시 애니메이션 정지, 배경음/효과음 음소거.

## 알려진 제약
- ES 모듈 사용 → `file://` 더블클릭 불가, **로컬 서버 필요**(README).
- 개발 환경(Node.js 부재)로 인해 최종 브라우저 플레이 점검은 사용자 측에서 수행.
