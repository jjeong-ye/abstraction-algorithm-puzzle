# 요구사항 (requirements)

## 목표
2022 개정 중학교 정보 교과의 **추상화·알고리즘**을 퀴즈가 아닌 **분석·조작·실행·수정·설명** 활동으로 배우는 웹 게임.

## 대상
중1~3, 프로그래밍 입문자.

## 기능 요구사항
1. 시작 화면(이름/번호 입력) → 월드 선택 → 스테이지 선택 → 게임 → 결과.
2. **3개 월드, 24개 스테이지**를 모두 구현하고 각 스테이지가 실제로 플레이 가능.
3. 각 스테이지: 학생 친화 문제문 + 교재 원문 보기 + **5단계 힌트** + 단계별/완전 해설.
4. 조작 기능: 실행취소, 다시시작, (해당 시) 되돌리기.
5. **교사 모드**: 모든 해설을 즉시 열람.
6. 설정: 소리 음소거, 움직임 줄이기, 전체화면.
7. 학습 기록: 통과 여부·최고 점수·시도·힌트·최소 이동/시간·설명·마지막 플레이 → **localStorage**.
8. 평가 4축: 추상화·알고리즘 정확성·효율성·설명.
9. 정답이 없거나 부족한 문제는 **직접 해결 + 프로그램 검증**.

## 비기능 요구사항
- 접근성: 마우스·터치·키보드, 색+글자/모양 병행, 큰 버튼·글자, 모바일/태블릿 대응, 움직임 줄이기.
- 성능: 서버 없이 정적 실행. 페이지 로드 즉시 동작.
- 유지보수: 24문제를 하드코딩하지 않고 **공통 엔진 + 데이터 파일** 구조.

## 제약/결정
- 권장 스택(Vite/React/TS)은 개발 환경에 Node.js 부재로 사용 불가 → **빌드리스 바닐라 ES 모듈**로 구현(모듈형 엔진 구조 유지).
- 그림 기반 문제(유추·격자·한붓그리기)는 교재 그림을 복사하지 않고 **규칙을 유지해 재구성**(answer-verification에 신뢰도 명시).
