# 🔴 UNLOCK 라이브 현황판 안내

교실 프로젝터에 "○○님이 월드2 3번 문을 열었어요!"를 실시간으로 보여주는 기능입니다.
학생 앱은 '문 열림' 신호만 보내고, 교사용 `board.html` 한 대(프로젝터)가 모아서 보여줍니다.

> 게임 안에서 **🎓 교사 → 📘 안내** 버튼을 누르면, 아래 내용이 화면으로도 정리돼 있어요.

---

## 1. 수업에서 쓰는 법 (제일 중요)
1. 게임 상단 **🎓 교사** → 코드 입력(●로 가려짐) → **이 수업 반**(예: 3-5) 입력 → 바로 월드로 입장
2. 상단 **📺 현황판** → 그 반의 현황판이 새 탭으로 열림 → **프로젝터**에 띄우기
3. 학생은 각자 앱에서 **같은 반 + 닉네임**(실명 대신 번호·모둠명)을 넣고 문제 풀기
4. 학생이 문제를 **처음 통과**할 때마다, 현황판 "🔓 최근 돌파" 목록 맨 위에 **반짝이며** 추가되고 "🏆 순위"가 갱신됨
- 현황판은 **오늘 기록만** 보여줘서 날짜가 바뀌면 자동으로 새로 시작됩니다(따로 지울 필요 없음).
- 현황판의 **⚙️ 반 변경**으로 다른 반으로 즉시 전환할 수 있어요.

## 2. 같은 학교 동료와 나눠 쓰기 (설정 필요 없음)
- 동료 선생님은 **이 사이트 링크만** 열면 됩니다. 코드 수정·배포 전혀 없음.
- 각자 🎓 교사 → 자기 반만 입력하면 끝. 반코드(2-1, 3-5…)는 한 학교 안에서 유일하므로 서로 안 섞여요.
- 즉, 준비는 '교사마다'가 아니라 **학교에 한 번**이면 됩니다.

## 3. 처음 한 번만 하는 설정 (학교당 1회)
### 1) 구글 시트 + Apps Script 배포
1. 구글 드라이브 → 새 **스프레드시트** 생성
2. [확장 프로그램] → [Apps Script] → 기존 코드 지우고 **`apps-script.js`** 전체 붙여넣기 → 저장
3. (선택) 편집기에서 함수 **`createGuideSheet`** 를 한 번 ▶ 실행 → 시트에 예쁜 **📖 사용안내** 탭 생성
4. [배포] → [새 배포] → 유형 **웹 앱** (실행: 나 / 액세스: 모든 사용자) → 나온 **`.../exec` URL 복사**

### 2) 게임과 연결 — 방법 A 또는 B
- **방법 A (기본, 코드 수정):** `src/live-config.js` 에서 `enabled: true`, `apiUrl: "복사한 /exec URL"` 로 저장 후 사이트 배포.
- **방법 B (코드 수정 없음, 추천):** 사이트는 그대로 두고, 학생에게 아래 형태의 링크를 나눠주기
  ```
  https://내사이트주소/index.html?api=<복사한 /exec URL>&class=<반>
  ```
  게임 안 **📘 안내 → 🔗 학생 링크 만들기**로 이 링크를 자동으로 만들 수 있어요(자동 복사).
  → 다른 학교도 이 방식이면 코드·재배포 없이 자기 백엔드에 연결됩니다.

## 4. 다른 "학교"에서 쓸 때
- 학교가 다르면 **기록 시트를 따로** 두세요(학교끼리 안 섞이고, 데이터도 각 학교 안에만 남음).
- 그 학교의 한 분이 시트를 **사본**으로 만들어 위 "3. 처음 설정"을 한 번만 하면, 그 학교 동료들은 다시 **링크만** 열면 됩니다.

## 5. 참고 / 개인정보
- 쌓이는 정보는 **닉네임 + 몇 번 문을 열었나** 뿐입니다(성적·실명 아님). 학생에게 **실명 금지**를 안내하세요.
- 웹앱은 '모든 사용자' 접근이라 URL을 아는 사람은 기록을 보낼 수 있어요. 민감정보는 넣지 마세요.
- 기록을 완전히 비우려면 구글 시트 **`log` 탭** 내용을 지우면 됩니다.
- 라이브 기능을 끄려면 `src/live-config.js` 의 **`enabled: false`** 로만 두면 됩니다(게임은 그대로 동작).
