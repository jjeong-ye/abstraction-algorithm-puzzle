# UNLOCK · 추상화와 알고리즘 퍼즐 방탈출

잠긴 문을 하나씩 열며 탈출하는 **방탈출형 퍼즐 게임**입니다. 2022 개정 중학교 정보 교과의 **추상화·알고리즘**을 중학생이 재미있게 익히도록 만들었습니다.

학습 자료 출처: 최재혁, 「퍼즐을 이용한 창의성 교육」(신라대학교, 2013).

## 교사 · 학생 화면
- **교사 (기본 주소)**: 사이트 주소를 그냥 열면 **교사용 화면(4개 버튼)** 이 바로 나옵니다. 별도 로그인·비밀번호 없음.
  - 📘 사용 방법 · 🔑 방 코드·학생 접속(QR) · 📺 현황판 열기 · 🎮 게임·문제 풀이(정답·해설 포함)
- **학생 (QR·링크)**: 교사가 보여준 **QR 또는 링크**(`?g=방코드`)로 들어오면 **닉네임만** 입력하고 바로 문제를 풉니다.
  - QR·링크에 방 코드가 이미 들어 있어 학생은 코드를 외우거나 입력할 필요가 없습니다.
  - 닉네임은 **실명 금지**(현황판에 표시되므로) — 번호·모둠명·별명 권장.

## 방탈출 방식
- **문 잠금·해제**: 각 월드 안에서 문이 순서대로 열립니다. 앞 문을 통과해야 다음 문이 열려요. (통과 🔓 / 지금 열 수 있는 문 🗝️ / 잠긴 문 🔒)
- **난이도 순 정렬**: 스테이지가 **기초 → 기본 → 도전** 순으로 배치됩니다.
- **월드는 자유 선택 + 부드러운 안내**: 월드(주제)는 언제든 고를 수 있고 추천 신호만 줍니다(강제 아님).
- **탈출 연출**: 정답 시 색종이 폭발 + 효과음 + "🔓 다음 문이 열렸어요!" 안내.

## 라이브 현황판 (선택 기능)
교실 프로젝터에 학생들의 문 돌파를 실시간으로 띄웁니다.
- 구글 시트 + Apps Script(`live/apps-script.js`) 백엔드에 연결되어 있습니다(기본 제공 백엔드 사용).
- **방 코드**는 현황판(구글 시트)에서 **어느 교실 기록인지 분류하는 값**입니다. 방 코드가 다르면 학교·반끼리 기록이 안 섞입니다. (보안용 아님)
- 현황판은 **오늘 기록만** 표시하고 약 2초마다 갱신됩니다.
- 다른 반이면 🔑 방 코드 창의 **🔄 새 코드**로 새 QR을 만들면 됩니다.
- 이 기능을 끄려면 `src/live-config.js`의 `enabled: false`.

## GitHub Pages 배포 (URL로 사용)
GitHub Pages는 HTTPS로 서빙하므로 **이 폴더를 그대로 올리면 바로 동작**합니다(모든 경로 상대경로, 빌드 불필요).
1. 새 저장소 생성.
2. **이 폴더 안의 파일 전부**(index.html, styles.css, src/, live/)를 저장소 **루트**에 올립니다.
3. 저장소 **Settings → Pages → Deploy from a branch → `main` / `/(root)`** → 저장.
4. 1~2분 후 `https://<사용자>.github.io/<저장소이름>/` 로 접속.
   - 파일명 대소문자가 정확히 일치해야 합니다. 학생 진행 기록은 각자 브라우저 localStorage에 저장됩니다.
   - 업데이트 후 화면이 그대로면 **Ctrl+Shift+R**(하드 새로고침).

## 로컬에서 열기 (개발용)
ES 모듈을 쓰므로 `index.html`을 더블클릭하면 동작하지 않습니다. **로컬 서버**로 여세요.
- VS Code/Kiro 확장 **Live Server** → `index.html` 우클릭 → *Open with Live Server*, 또는
- `python -m http.server` 등 임의의 정적 서버.

## 폴더 구조
```
UNLOCK/
├─ index.html            게임 본체 (교사 화면 = 기본)
├─ styles.css
├─ src/
│  ├─ data.js            문제 데이터(원문·정답·해설·태그·엔진설정)
│  ├─ engines.js         인터랙션 엔진(학습 유형별)
│  ├─ app.js             화면 전환·게임 셸·문 잠금·점수·기록
│  ├─ ui.js              공용 UI(소리·색종이·모달·SVG 도형·해설)
│  ├─ storage.js         localStorage 학습 기록 (키: puzzle-escape-v1)
│  ├─ live-config.js     라이브 현황판 연동 설정
│  └─ verification/      정답 검증 solver (런타임 정답 판정에 사용)
└─ live/
   ├─ board.html         교사용 라이브 현황판(프로젝터)
   └─ apps-script.js     구글 Apps Script 백엔드 코드(자체 배포 시 참고)
```

## 기술 참고
빌드가 필요 없는 **바닐라 ES 모듈 + HTML/CSS**로 구현했습니다. 진행 기록 저장 키는 `puzzle-escape-v1`입니다.
