# UNLOCK · 추상화와 알고리즘

잠긴 문을 하나씩 열며 탈출하는 **방탈출형 퍼즐 게임**입니다. 2022 개정 중학교 정보 교과의 **추상화·알고리즘**을 중학생이 재미있게 익히도록 만들었습니다.
학습 자료 출처: 최재혁, 「퍼즐을 이용한 창의성 교육」(신라대학교, 2013) — PDF를 분석해 여러 스테이지로 재구성했습니다.

## 무엇이 다른가 (방탈출 방식)
- **문 잠금·해제**: 각 월드 안에서 문이 순서대로 열립니다. 앞 문을 통과해야 다음 문이 열려요. (통과 🔓 / 지금 열 수 있는 문 🗝️ / 잠긴 문 🔒)
- **난이도 순 정렬**: 스테이지가 **기초 → 기본 → 도전** 순으로 배치되어, 쉬운 것부터 자연스럽게 올라갑니다.
- **월드는 자유 선택 + 부드러운 안내**: 월드(주제)는 언제든 고를 수 있고, "🗝️ 여기부터 추천 / 🔒 앞 월드 먼저 추천" 같은 신호만 줍니다(강제 아님).
- **탈출 연출**: 정답 시 색종이 폭발 + 효과음 + "🔓 다음 문이 열렸어요!" 안내.
- **교사 모드**: 상단 🎓 버튼 + 코드로 모든 문을 즉시 열어 원하는 문제로 바로 이동(수행평가·발췌용).

## 실행 방법 (중요)
ES 모듈을 사용하므로 `index.html`을 그냥 더블클릭하면(파일 프로토콜) 브라우저 보안정책 때문에 동작하지 않습니다. **로컬 서버로 열어야 합니다.**

- **가장 쉬운 방법 (VS Code / Kiro):** 확장 프로그램 **Live Server** 설치 후 `index.html`에서 우클릭 → *Open with Live Server*.
- **포함된 서버 사용:** 이 폴더에서 `server.ps1` 실행 → 브라우저에서 `http://localhost:8123/index.html` 접속.

## GitHub Pages 배포 (URL로 사용)
GitHub Pages는 HTTPS로 서빙하므로 **이 폴더를 그대로 올리면 바로 동작**합니다(로컬 서버 불필요, 모든 경로가 상대경로).

1. 새 저장소 생성(예: `unlock-puzzle`).
2. **이 폴더 안의 파일들**(index.html, test.html, styles.css, src/, docs/ 등)을 저장소 **루트**에 올립니다.
   - `.gitignore`가 교재 PDF·Node 런타임·node_modules를 자동 제외합니다. (PDF는 저작권 자료이므로 공개 게시 금지)
3. 저장소 **Settings → Pages → Deploy from a branch → `main` / `/(root)`** 선택 → 저장.
4. 1~2분 후 `https://<사용자>.github.io/<저장소이름>/` 로 접속. (자동 검증 페이지: `.../test.html`)
   - 파일명 대소문자가 정확히 일치해야 합니다. 학생 진행 기록은 각자 브라우저 localStorage에 저장됩니다.

## 폴더 구조
```
UNLOCK/
├─ index.html            게임 본체
├─ test.html             자동 검증 테스트 실행 페이지
├─ styles.css
├─ server.ps1            포함된 초경량 로컬 서버(포트 8123)
├─ teacher-guide.md      교사용 완전 가이드
├─ src/
│  ├─ data.js            문제 데이터(원문·정답·해설·태그·엔진설정)
│  ├─ engines.js         인터랙션 엔진(학습 유형별)
│  ├─ app.js             화면 전환·게임 셸·문 잠금·점수·기록
│  ├─ ui.js              공용 UI(소리·색종이·모달·SVG 도형·해설)
│  ├─ storage.js         localStorage 학습 기록 (키: puzzle-escape-v1)
│  └─ verification/      정답 검증 solver + 테스트
├─ docs/                 요구사항·설계·검증 등 문서
└─ _tools/               PDF 분석·테스트용 스크립트(배포 불필요)
```

## 게임 구성
- **월드 0 맛보기**, **월드 1 추상화**, **월드 2 알고리즘**, **월드 3 추상화＋알고리즘**
- 각 스테이지: 문제 분석 → 조작/실행 → 힌트 → 단계별·완전 해설 → 설명 쓰기(평가)
- 기능: 학생 이름, 월드/문 선택, 문 잠금·해제, 힌트, 실행취소, 다시시작, 교사 모드, 소리·움직임 줄이기, 전체화면, localStorage 기록

## 기술 참고
빌드가 필요 없는 **바닐라 ES 모듈 + HTML/CSS**로 구현했습니다. 진행 기록 저장 키는 자유 선택 버전과 겹치지 않도록 `puzzle-escape-v1`을 사용합니다.
